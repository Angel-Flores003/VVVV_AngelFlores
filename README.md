# VVVV_AngelFlores 🎮

un joc de plataformes en 2D on has de controlar la gravetat per avançar.

## 🕹️ Controls

| Tecla / Botó | Acció |
| :--- | :--- |
| **A** o **Fletxa Esquerra** (`←`) | Moure's cap a l'esquerra |
| **D** o **Fletxa Dreta** (`→`) | Moure's cap a la dreta |
| **Espai** (`Space`) | Canviar la gravetat |
